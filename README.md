# 🔒 Password Generator

Простой и быстрый консольный генератор случайных паролей на **Python**. Программа позволяет пользователю сгенерировать стойкий пароль заданной длины из символов латинского алфавита и цифр.

---

## 🚀 Особенности

* 🎲 **Случайная генерация**: Использование модуля `random` для создания непредсказуемых комбинаций.
* 📏 **Настраиваемая длина**: Пользователь сам выбирает, скольких символов будет итоговый пароль.
* 💬 **Интерактивный ввод**: Удобный диалог в консоли.

---
